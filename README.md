# DPM Meter

一个用于《战锤40K：暗潮》的 DPM（每分钟伤害）HUD 统计 mod。它把当前玩家最近 60 秒造成的伤害换算成每分钟伤害，显示在个人 HUD 面板旁，同时保留本局最高 DPM。

## 功能

- 在个人 HUD 上显示当前 DPM 和本局最高 DPM，例如 `DPM: 12.5K / 24.8K`。
- 使用 60 秒滑动窗口，旧伤害会自动移出统计。
- 记录每名玩家的数据，并在任务结束时输出本局统计摘要。
- 数字使用与帧率无关的平滑过渡，避免数值跳动过于生硬。
- 支持位置、字号、字体、颜色、双色或三色渐变、动态流动和 Discord 风格流光设置。
- 提供 `dpm_reset` 和 `dpm_preview` 命令，方便清空数据或预览渐变样式。

## 大致原理

mod 通过 DMF hook 监听生命值系统的 `add_damage`，并兼容 `AttackReportManager:add_attack_result` 作为补充入口。每次确认是玩家对敌方小怪造成的有效伤害后，记录时间戳、伤害值和玩家 ID。

更新循环持续清理超过 60 秒的记录，把窗口内的伤害相加作为当前 DPM；同时单独维护本局最高值。HUD 侧只给个人玩家面板添加一个原生文本 widget，再用游戏文本的颜色标签逐字生成渐变和流光效果，因此不会另起一个背景面板。

## 安装

1. 安装 Darktide Mod Framework（DMF）。
2. 将 `dpm_meter` 文件夹复制到游戏的 `mods` 目录。
3. 在 mod 管理器中让 `dpm_meter` 排在 DMF 后面加载。
4. 进入任务后打开 mod 设置调整位置、字号和颜色。

## 说明

- 统计对象是玩家对敌方小怪造成的有效伤害，不是承伤，也不是武器面板上的理论数值。
- 当前显示挂在个人 HUD 上，队友的完整 DPM 数据主要用于任务结束摘要。
- 这是一个纯客户端 HUD 统计工具，不修改武器、敌人血量或任务结算。
